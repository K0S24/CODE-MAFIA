## Short Description
A multiplayer browser game where players collaborate on a shared code editor — but one player is secretly sabotaging the code.

## Full Description
Real-time multiplayer coding game inspired by Among Us. Players join a lobby, get assigned secret roles (Civilian or Imposter), and work together in a shared Monaco Editor to solve Python coding challenges. The Imposter secretly breaks the code while Civilians try to fix it. After the timer ends, players vote on who they think the saboteur is. Built with live cursor tracking so every player's edits are visible in their unique color.
